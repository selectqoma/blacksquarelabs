Vector paths are unchanged; each root SVG has the corresponding brand color applied as `fill`. This pinned release includes all eight requested marks.

Colors were verified against the same pinned release’s [brand metadata](https://raw.githubusercontent.com/simple-icons/simple-icons/11.15.0/_data/simple-icons.json). Notion uses black (`#000000`) and GitHub retains its official near-black (`#181717`).

Each SVG was checked to contain only `svg`, `title`, and `path` elements, with no scripts, links, or external references.
